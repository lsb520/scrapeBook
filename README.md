# 小说爬取器

一个本地桌面小说爬取工具。输入小说网站的目录页地址后，程序会识别章节链接，逐章抓取标题和正文；左侧以“小说名 -> 章节”的树形书架展示，点击章节名可在右侧阅读，并可导出整本小说 TXT。

界面采用接近 Cursor 的扁平黑色主题，默认字体为 12px。

## 直接运行

双击：

```bat
run_app.bat
```

或在命令行运行：

```bat
python app.py
```

## 打包 exe

双击：

```bat
build_exe.bat
```

打包完成后，生成文件位于：

```text
dist\NovelScraper.exe
```

如果电脑还没有安装 PyInstaller，打包脚本会先执行 `python -m pip install pyinstaller`。

## 使用方式

1. 打开程序。
2. 在顶部输入小说的目录页地址，地址需要以 `http://` 或 `https://` 开头。
3. 可按需要调整“并发”和“间隔”。默认并发 `12`、间隔 `0.03` 秒；如果网站不稳定，可以把并发降到 `4` 到 `8`。
4. 点击“开始爬取”。
5. 小说会作为一级节点加入左侧书架，章节序号和章节名会作为二级节点显示。
6. 点击左侧章节名，在右侧阅读正文。
7. 点击“保存TXT”，导出整本小说。

如果保存时仍有章节没有获取正文，程序不会直接导出残缺 TXT，而是先询问是否补齐缺失章节；爬取过程中点击保存，会等当前任务完成后再保存。

章节正文支持分页抓取。程序会优先读取页面里的“下一页/下页/Next”等分页链接，也会识别常见的章节分页地址，例如：

```text
11385-2.html
11385_2.html
chapter/2
?page=2
```

旧版本保存过的单页章节缓存会被视为待补齐，重新爬取后才会参与 TXT 导出。

## 快速模式

程序现在支持“通用解析 + 站点规则”两种模式。

对 `sudugu.org` 已内置专用规则：

1. 目录页直接读取 `#list` 章节目录。
2. 正文页直接读取 `.con` 正文区域。
3. 分页优先读取 `.prenext` 中的“下一页”。
4. 如果站点提供 `/txt/?id=...` 整本 TXT 文件，会优先尝试 TXT 快速通道，成功后直接按章节标题切分并填充正文；失败后自动回退到并发分页爬取。

通用网站仍会使用自动识别目录、正文和分页的逻辑。

## 历史书架

爬取过的小说会留下历史记录。下次打开程序时，左侧只显示收起的小说名；展开小说名时，会按记录的目录地址重新刷新该小说。

每本小说右侧有一个叉号：

1. 第一次点击叉号，会变成红色确认状态。
2. 短时间内再次点击，会彻底清除这本小说的历史记录和本地数据。
3. 超时未再次点击，会自动恢复普通叉号。

## 数据保存

爬取进度会自动保存到：

```text
data\books\
```

每本书会保存为一个 JSON 文件。导出的 TXT 文件位置由你在保存窗口中选择。

## 注意

这个工具适合静态 HTML 小说目录页。部分网站如果使用登录、验证码、强反爬、Cloudflare 或纯 JavaScript 动态渲染，可能无法直接抓取。

新版目录识别会优先寻找章节目录容器，并按小说目录页路径过滤链接，尽量避免把底部推荐小说或站点导航混进章节列表。
